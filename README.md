# نظام إدارة مراكز الدعم التعليمي

## نظرة عامة
تطبيق SaaS متكامل لإدارة مراكز الدعم التعليمي مع نظام مصادقة كامل يربط بين المعلمين والطلاب.

## المميزات الرئيسية

### 🔐 نظام المصادقة
- تسجيل الدخول والتسجيل مع Supabase Auth
- حماية الجلسات وتخزين آمن للمعلومات
- تسجيل الخروج الآمن
- التحقق التلقائي من حالة المصادقة

### 📊 لوحة التحكم
- إحصائيات شاملة عن المراكز والمعلمين والطلاب
- الحصص القادمة
- النشاطات الأخيرة
- رسوم بيانية تفاعلية

### 🏫 إدارة المراكز
- إضافة وتعديل وحذف المراكز
- معلومات تفصيلية لكل مركز
- تتبع السعة والطلاب والمعلمين

### 👨‍🏫 إدارة المعلمين
- قائمة كاملة بالمعلمين
- إضافة وتعديل وحذف معلمين
- ربط المعلمين بالمراكز والمواد

### 🎓 إدارة الطلاب
- قائمة الطلاب مع بطاقات تفاعلية
- معلومات الاتصال والتسجيل
- تتبع المجموعات التي ينتمي إليها كل طالب

### 👥 إدارة المجموعات
- إنشاء مجموعات تعليمية
- ربط المعلمين بالطلاب
- جدولة الحصص
- تتبع السعة والطلاب

## البنية التقنية

### Frontend
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - للكتابة الآمنة
- **Tailwind CSS v4** - للتصميم
- **Lucide React** - للأيقونات

### Backend
- **Supabase** - قاعدة البيانات والمصادقة
- **Hono** - إطار عمل خفيف للـ Edge Functions
- **Deno** - بيئة تشغيل JavaScript/TypeScript

## كيفية البدء

### التسجيل
1. افتح التطبيق
2. انقر على "سجل الآن"
3. أدخل الاسم الكامل، البريد الإلكتروني وكلمة المرور (6 أحرف على الأقل)
4. انقر على "إنشاء الحساب"

### تسجيل الدخول
1. أدخل البريد الإلكتروني وكلمة المرور
2. انقر على "تسجيل الدخول"
3. سيتم توجيهك إلى لوحة التحكم

### استخدام التطبيق
- استخدم القائمة الجانبية للتنقل بين الأقسام المختلفة
- يمكنك إضافة وتعديل وحذف السجلات في كل قسم
- جميع البيانات محفوظة بشكل آمن في Supabase

## API Endpoints

### المصادقة

#### POST `/make-server-56cffd48/auth/signup`
إنشاء حساب جديد
```json
{
  "name": "أحمد محمد",
  "email": "ahmed@example.com",
  "password": "password123"
}
```

#### POST `/make-server-56cffd48/auth/signin`
تسجيل الدخول
```json
{
  "email": "ahmed@example.com",
  "password": "password123"
}
```

#### GET `/make-server-56cffd48/auth/me`
الحصول على معلومات المستخدم الحالي
- يتطلب: Authorization header مع access token

#### POST `/make-server-56cffd48/auth/signout`
تسجيل الخروج
- يتطلب: Authorization header مع access token

## الأمان

- جميع كلمات المرور مشفرة تلقائياً بواسطة Supabase Auth
- الجلسات محمية باستخدام JWT tokens
- تأكيد البريد الإلكتروني تلقائي (يمكن تفعيل التأكيد اليدوي)
- جميع طلبات API محمية بـ CORS
